# Easywave for Home Assistant

[![hacs_badge](https://img.shields.io/badge/HACS-Custom-orange.svg)](https://github.com/custom-components/hacs)

Custom integration for Eldat devices in Home Assistant.

## Installation

### HACS (Recommended)

1. Open HACS
2. Go to "Integrations"
3. Click the three dots → "Custom repositories"
4. Add this repository URL
5. Select category "Integration"
6. Install and restart Home Assistant

### Manual Installation

Copy `custom_components/eldat_plugin` to your Home Assistant config directory.

## Configuration

Configure through the Home Assistant UI.
